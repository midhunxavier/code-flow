GET STARTED

Choose how you
want to work.

Run the local web app, connect your CLI, or download the desktop preview. Use your existing coding CLI login.

01 / LOCAL WEB APPMACOS · LINUX · WSL2

Open in your browser

Install Node.js 22.13+, Git 2.38+, and a supported CLI (claude, codex, or agy). Sign in to that CLI, then run:

npm install -g @midhunxavier/code-flow@preview codeflow

The app opens locally in your browser. If it does not, open the private sign-in link printed in the terminal. Keep the terminal open; press Ctrl+C to stop.

More installation options ↗
02 / YOUR CLIEXPERIMENTAL

Use inside Claude or Codex

Install the launcher with npm using the web app instructions. In your Git project, set up the connection:

cd /path/to/your-git-project codeflow init codeflow doctor

Start claude or codex in that project, trust it and approve the MCP connection. In Claude, invoke /codeflow; in Codex, invoke $codeflow. Then describe the task and review the proposed approach before starting.
