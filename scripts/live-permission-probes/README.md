# Opt-in real CLI probes

These scripts invoke real models with the CLI's existing login and consume provider usage. They are not part of the deterministic test suite. They use `gpt-6.1-sol` and `claude-sonnet-5-5`, the models tested in the verification report; adjust them explicitly if unavailable. The original live probe tests an invalid Antigravity managed receipt as a pre-inference rejection; the dedicated managed probes below exercise its supported executor.

Run `node --import tsx scripts/live-permission-probes/live.ts`. It creates a temporary Git fixture, sibling sentinel and local HTTP server and prints the root. Record the result; the fixture remains for inspection. File and terminal tests touch only that fixture. Claude runs second, so its `terminalLocal` value may be left from Codex: evaluate the emitted tool denial and per-turn HTTP count, not that file alone.

Pass the resulting `<root>/workspace` to `mcp.ts`, `delegation.ts` or `browser.ts` in this directory. MCP uses an ephemeral local capability returning a fixed marker. The delegation probe deliberately tries one harmless native child to detect a broken restriction. The browser probe creates and closes a new tab for its own local server; it must not inspect existing tabs. `PROBE_RESUME` and `PROBE_EFFORT` can test a **fixture** session's resume path and effort; do not supply a user task's session ID. Scripts emit observations, not broad certification; inspect tool results and the local server/sentinel evidence.

No script changes global provider settings. See `docs/worker-permission-verification.md` for the bounded findings and unsupported controls.

`node --import tsx scripts/live-permission-probes/antigravity.ts` independently creates a temporary custom agent allowing only `view_file` and tests it with `gemini-3.8-flash-low` (override with `PROBE_MODEL`). It asks for a fixture write and `printf PROBE` only if those tools are offered. No skip-permissions flag is used. It prints advertised tools, observed calls and the fixture write marker; startup tool listings and model self-reports alone do not establish enforcement. Raw events remain in a private file in the printed fixture directory. This research probe does not enable Antigravity in Auto or certify hooks, browser/MCP isolation, native delegation or recovery.

The separate offline prototype can be checked with `node --import tsx --test test/agy-isolation-fixture.test.ts`. It uses no provider or credentials. On macOS it exercises actual kernel denials against temporary fixtures; other platforms run configuration validation only. Run `node --import tsx scripts/live-permission-probes/isolated-antigravity.ts /absolute/path/to/agy` to check CLI startup and discovery inside the same network-denied boundary. This command leaves its printed fixture directory for inspection and prints only bounded status fields, not raw authentication diagnostics. It accepts no prompt or native session and cannot enable Auto. Do not authenticate inside this offline prototype or copy a host login into it: authenticated execution and inference networking are still unresolved.


`node --import tsx scripts/live-permission-probes/managed-antigravity.ts` tests the production macOS/CLI 1.4.4 or 1.4.5 file-only adapter with `gemini-3.8-flash-low`, using the existing native Keychain login. It never reads credential values or imports global settings. Two turns exercise a workspace edit, structured JSON, a fresh read-only invocation, a synthetic outside symlink, a workspace hook marker and a loopback browser fixture. Provider homes are cleaned after each turn; the synthetic project remains at the printed path. Unknown runtime versions fail closed. Missing tools and marker checks are bounded observations, not forced-tool-call certification.

`node --import tsx scripts/live-permission-probes/managed-antigravity-auto.ts` runs a tiny real Auto job with `gpt-6.1-sol`/low as coordinator, an Antigravity file worker and independent review. It consumes both providers' usage, uses a temporary Git repository, and cancels after four minutes. It requires a completed verified run with at least one isolated Antigravity step; it does not install or sign into either provider.

`node --import tsx scripts/live-permission-probes/antigravity-refresh.ts` observes native authentication during a normal isolated `agy models` request. It does not log out, force expiry, change clocks, export tokens, edit the Keychain or request broader permissions. It prints only bounded metadata and deletes its private native log/profile. Normal renewal, when due, remains owned by Antigravity and may update native tokens.

Exit codes: **0** means a native refresh event and successful discovery were observed; **2** means discovery worked but refresh was not observed (inconclusive); **1** means the request or native authentication failed. No refresh event while a token is still valid is expected. A native success event does not attest successful credential persistence; the report labels that separately. `expiredTokenRefreshVerified` requires an expired-at-load observation as well. Run this probe again when natural renewal is due; do not edit expiry or revoke a login to make it pass. No background polling or scheduled task is installed.

Pass `--native` to `managed-antigravity-auto.ts` to explicitly exercise unrestricted Antigravity using the existing host profile. This removes Code Flow's Antigravity isolation, permits its terminal, and leaves browser/MCP/hooks/native agents to provider configuration. The synthetic task requests only file editing and a terminal test. It still uses portable turns and records `agy-native-v1`; a valid saved login is required.
