# Review inbox

Open Inbox from the sidebar. Filter to a project or attention type, then open an item to answer its question or inspect its result. Sorting the inbox does not approve or publish work.

## Work through attention items

The **Inbox** sidebar destination groups attention for manual and unattended runs.
Questions and approvals, blocked teams, unread failed/interrupted runs and pending
automation results appear there. Archived and handled items are excluded.

Run priority comes first, followed by attention type and then the oldest waiting
item. Group by project, repository or attention type, or use one list. Search task
text, run IDs, repository paths, source titles and trigger names. Project scope
continues to apply; the page reports attention items outside the current scope.

Open the run to answer questions, inspect failures or review evidence. Tool
permissions remain in their scoped approval inbox. No result is merged or approved
by sorting, filtering or opening this page. Grouping is a presentation choice and
does not change dispatch order; the explicit run priority controls dispatch too.
